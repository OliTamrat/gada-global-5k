Executive Summary

Olink Technologies is pleased to present this proposal for the Gada Global 5K — an annual community running event celebrating Oromo heritage and the Irrecha thanksgiving festival. Scheduled for October 3, 2026 at Rock Creek Parkway in Washington, DC, this inaugural event will bring together up to 500 runners and community members.

This document outlines the complete digital platform built to power the event — from marketing and athlete registration to merchandise sales and secure payment processing. The platform is designed as a reusable foundation for annual events going forward.

What We Are Delivering
A fully custom Next.js web application with athlete registration, 3-tier pricing, Stripe payment processing, e-commerce merch shop with cart, animated hero with video background, live countdown, and premium sports-inspired design — ready to launch and accept registrations.
Platform Overview
Marketing Website
6-section landing page with video hero, animated typing title, countdown timer, and cultural content
Registration System
3-tier pricing (Early Bird $25, Standard $35, Race Week $45) with Stripe Checkout
Merchandise Store
3 products with size selection, shopping cart, quantity controls, and Stripe payment
Responsive Design
Mobile-first, DM Sans + Inter typography, SVG icons, scroll animations, dark/cream palette
Technology Stack
Next.js 16 TypeScript Stripe Tailwind CSS v4 Vercel React Context DM Sans + Inter CSS Animations
