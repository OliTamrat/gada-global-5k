# ADR-0005 — Four content decisions taken from timeout defaults

**Status:** provisional — needs organizer confirmation · **Date:** 2026-08

## Context
During a working session, four questions timed out and defaults were
applied: (1) the $1,200 purse split across two divisions rather than one
combined top-three; (2) the festival ending at noon (source note read
"7am-12am"); (3) removing the Lincoln Memorial card after the venue
change; (4) updating the website only, not other materials.

## Decision
Record them as *provisional*. The website reflects them; print and paid
promotion must not, until an organizer confirms each.

## Consequences
This ADR is the checklist for that conversation. When confirmed, a
follow-up ADR marks them accepted (or changes them) and this one is
superseded.
